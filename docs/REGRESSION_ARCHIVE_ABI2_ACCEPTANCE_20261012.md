## 1. 结论

本轮完成这三个指定项目的验收。发现并修复了归档流生命周期缺陷，以及阻止独立组件打包的旧校验条件。音量失败源于过时的测试夹具；原版与重建版模式切换在控制消息顺序后得到相同捕获状态，因此没有为这两项修改已经正确的播放器行为。

同一份 x86 Release EXE／DLL 在 Windows 11、XP SP3、Win7 SP1 验证通过，并通过 XP／Win7 静态导入审计。按用户要求由 Windows 11 代表现代系统验证，不记为 Windows 10 实机测试。

## 2. 音量完整回归失败

历史记录见 [皮肤审计 §27.4](SKIN_PARSER_AND_COMPONENT_ORDER_AUDIT_20261011.md)：当时只运行 `--volume-feedback`，完整 `--main-volume` 曾报告焦点控件滚轮路由失败。

本次重新编译完整测试，首先复现期望音量 50、实际 53。测试在无皮肤、使用原生 trackbar 的窗口里，手动设置 `pressed_skin_element_` 并捕获主窗口来模拟皮肤拖动；当前实现依据真实 slider 的 `dragging` 状态，这种夹具已不能代表正在拖动的控件。

修正私有 `tests/ui/main_volume_tests.inc`：

- 原生控件测试用 `SetCapture(player.volume_)` 建立真实捕获，皮肤拖动由已有的皮肤消息测试覆盖。
- 测试窗口设置为独立置顶工具窗口；滚轮路由前验证 `WindowFromPoint` 确实命中测试音量控件，避免其他窗口遮挡被误报为路由缺陷。
- 保留数值、静音、音频增益、滚轮步长与上下限、提示超时、菜单和手动输入断言；没有删除失败断言或放宽期望。

修正后完整 `--main-volume` 在三个系统均通过，包含 24 组皮肤按下／保持／移动／释放／取消测试、提示像素和计时器。生产音量实现未改动。

## 4. 实际修复：状态接口绕过宿主流所有权

`src/audio/archive_member.cpp` 的 `OwnedArchiveStream` 持有取消函数及上下文；此前 `QueryInterface` 将未知接口直接转交内部 DLL 流。获取状态接口后，它的 `IUnknown` 指向内层对象，不再指向宿主包装器。

因此“保留状态接口 → 释放外层 IStream → 继续查询／克隆／最终释放”的顺序可能让取消上下文提前销毁，而内层流仍保留该上下文地址。新增测试在修复前明确失败于 `archive wrapper COM identity`，没有故意执行悬空回调来触发系统崩溃弹窗。

修复内容：

1. SDK 公开 ABI 2 已在使用的状态接口 GUID 和单个 `Snapshot` 方法；没有更改既有 GUID、vtable 调用约定、函数表布局、结构大小、导出名或序号。
2. 外层流自身实现状态接口；所有接口共用同一控制 `IUnknown` 和引用计数，不再返回内部对象。
3. `Snapshot` 通过已经验证的 `api.status` 查询内层；`Clone` 继续包装克隆，并共享取消上下文。
4. 保持成员析构顺序：先释放内层流，再释放取消上下文，使内层析构仍可安全检查取消。
5. 同步播放器的固定 SDK 副本及清单。

释放顺序回归确认：状态接口单独保留时上下文仍有效；经状态接口重新取得 IStream 并克隆后仍能读取；最终释放 Clone 后上下文不泄漏。新宿主包装器也通过了修复前的 ABI 2 DLL 测试，确认本次接口声明整理不要求 ABI 升级。

测试关闭时遵循既定契约：先 Release 所有流，再 `clear_cache`，最后卸载 DLL。原有宿主 `TtpCommRuntime::Shutdown` 已执行缓存清理；本次为新增测试补上相同关闭步骤，避免缓存任务在 DLL 卸载阶段等待线程。

ABI 2 在此前 232 项上扩充至 271 项，重点补充：

- 四个 Clone 并发进行各 64 次 Seek／Read，与参考字节逐次对比。
- `clear_cache` 和原始流释放后，活跃 Clone 的数据、任务 ID 和独立游标仍有效。
- 取消一个读取者及其 Clone，不中断另一个独立打开但共享缓存任务的读取者。
- 延续 128 MiB 成员、完整解压前前缀读取、缓存复用／失效、最后读取者取消、分卷不复用及终端错误检查。

首轮 VM 运行曾因测试部署目录不符导致解码测试找不到 CUE 样本，修正路径后单独通过；最终重新部署整套运行，九项退出码全部为 0。保留首轮日志，不将部署失败伪记为产品修复。

## 6. 构建与发行包

- 统一 x86 Release，子系统 5.01，沿用 VC-LTL／YY-Thunks。
- DLL：67 个旧导出＋4 个扩展；7 个 DLL、246 项静态导入通过 XP／Win7 审计。
